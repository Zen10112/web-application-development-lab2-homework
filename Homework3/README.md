# HW3 – Flash Sale (Stage 1)

React + TypeScript + Vite. This stage includes 8 sample products, responsive catalog UI, countdown placeholder, and order status placeholder.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Scope

No countdown engine, reservation, concurrency, inventory mutation, or checkout yet. Product images are locally stored SVG placeholders in `public/images/` (no external internet required).

## Git

This stage can be committed as the first of at least 8 atomic Conventional Commits required by the homework. Commit each later functional milestone separately.
